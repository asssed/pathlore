# Pathlore

Интерактивные карты и гайды по играм: лут, квесты, секреты, билды, ачивки, fashion-сеты и умный поиск, который понимает неточный запрос.

Первая игра — Elden Ring. Публичный запуск запланирован на 8 февраля 2027.

- Архитектура: [docs/architecture.md](docs/architecture.md)
- Источники данных и лицензии: [docs/data-sources.md](docs/data-sources.md)
- Этапы и сроки: [docs/roadmap.md](docs/roadmap.md)

Тексты квестов и лора частично основаны на материалах [Eldenpedia](https://eldenring.wiki.gg/) под лицензией CC BY-SA 4.0. Elden Ring — товарный знак FromSoftware и Bandai Namco; Pathlore не связан с ними.
