# Pathlore

Интерактивные карты и гайды по играм: лут, квесты, секреты, билды, ачивки, fashion-сеты и умный поиск, который понимает неточный запрос.

Первая игра — Elden Ring + Shadow of the Erdtree. Публичный запуск запланирован на 8 февраля 2027.
