# Pathlore — контекст для Claude

Этот файл читается в начале каждой сессии. Claude не помнит прошлые чаты, поэтому всё важное живёт здесь и в `docs/`.

## Что это

Pathlore — веб-приложение с интерактивными картами и гайдами по играм. Цель: игрок находит нужное быстрее, чем через Google.

Главные преимущества:
- умный поиск по каждой игре, отвечает только из нашей базы, со ссылкой на точку на карте;
- трекинг прогресса с синхронизацией между устройствами;
- официальные названия из локализации игры на всех языках;
- позже — импорт сейва и десктоп-версия.

Полный план: https://claude.ai/artifact/AdjdL3pYY7XcGb9BmuG4bo (утверждён 4 ноября 2026).

## Роли

- **Claude:** весь код, архитектура, пайплайны данных, черновики гайдов, тексты.
- **Владелец (asssed):** аккаунты, домен, хостинг, деньги, ключи, проверка в игре, финальные решения.

Claude не вводит пароли, данные карт и документов, не проводит платежи. Удаление файлов и данных — только после подтверждения владельца. Отправка сообщений, публикации и покупки — каждый раз с отдельным подтверждением.

## Жёсткие правила по данным

1. **Нельзя** копировать данные Mapgenie, Fextralife и любых закрытых баз — даже «с другим дизайном».
2. Тексты с вики под CC BY-SA — только с атрибуцией; они бесплатны для всех и не могут быть платной частью.
3. **Файлы игры не коммитим и не публикуем.** Только извлечённые факты (статы, координаты, названия).
4. `eldenring.exe` и оригинальные файлы игры не изменяем. Распаковка — в отдельную папку.
5. Персональные данные пользователей из РФ хранятся на российском хостинге.

Подробности: `docs/data-sources.md`.
