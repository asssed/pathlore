# Pathlore — справочник проекта для новых чатов

> Этот файл автоматически подхватывается Claude Code в этой папке. Claude не помнит прошлые чаты —
> **весь контекст живёт в репозитории**. Язык общения — **русский**. Пользователь — Тим, владелец продукта.

## 1. Что это
Веб-приложение с интерактивными картами и гайдами по играм: игрок находит нужное быстрее, чем через Google.
Первая игра — **Elden Ring + Shadow of the Erdtree**, публичный запуск **8 февраля 2027**; вторая — Baldur's Gate 3 (~18 апреля 2027).
Козыри: умный поиск на естественном языке (только из нашей базы, со ссылкой на точку карты), трекинг прогресса
с синхронизацией ПК↔телефон, официальные названия на всех языках из локализации игры.

## 2. С чего начинать каждый чат
1. Прочитать этот файл.
2. Открыть текущий этап: [docs/stage-0.md](docs/stage-0.md) (когда этап закрыт — файл следующего этапа).
3. Свериться с [docs/decisions.md](docs/decisions.md) — там все принятые решения; не пересматривать их без запроса Тима.
4. Продукт целиком — [docs/plan.md](docs/plan.md) (утверждён 4 ноября 2026), техника — [docs/architecture.md](docs/architecture.md).

В конце работы: отметить сделанное в чек-листе этапа, новые решения — строкой в `decisions.md` (с датой и «почему»).

## 3. Роли
- **Claude:** весь код (архитектура, фронтенд, бэкенд, база, админка, карта, поиск), датамайн и пересчёт координат,
  черновики гайдов/билдов/ачивок, перевод, тексты для продвижения, документация в репозитории.
- **Тим:** аккаунты, домен, хостинг, Robokassa, ключи и пароли, деплой с паролями, GitHub-репозиторий,
  выгрузка файлов игры по инструкции Claude, проверка меток и квестов в игре, финальная вычитка, решения, публикации.
- Claude **не** создаёт аккаунты, не вводит пароли/ключи/платёжные данные и не платит — готовит инструкцию, Тим делает сам.

## 4. Жёсткие правила (нарушение = юридический или репутационный риск)
- **Данные только легальные:** датамайн игры (ERDB, Smithbox), вики под CC BY-SA 4.0 (Eldenpedia, с атрибуцией),
  публичные данные Steam, ручная проверка. **Нельзя** брать что-либо из Mapgenie, Fextralife и любых закрытых баз.
- **Файлы игры не распространяем и не коммитим** (`*.bdt`, `*.bhd`, `*.dcx`, распакованные ресурсы) — публикуем только факты.
  Выгрузки игры лежат вне репозитория или в папках из `.gitignore`.
- Тексты под CC BY-SA бесплатны для всех → платная часть (Pro) — это **функции**, а не эти тексты. Страница атрибуции обязательна.
- **Персональные данные пользователей из РФ хранятся в России** (аккаунты — на российском хостинге).
  За рубеж (например, в ИИ-сервис) уходят только обезличенные данные — текст запроса без идентификаторов.
- **Умный поиск отвечает только из нашей базы.** Нет совпадения → честно «не нашёл». Каждый ответ — ссылка на сущность/точку карты.
- Секреты (`.env`, ключи, пароли) никогда не попадают в репозиторий.

## 5. Стек (утверждён в плане; детали — architecture.md)
Next.js (React, TypeScript) · Leaflet (карта, `CRS.Simple`) · PostgreSQL + pgvector · Robokassa (самозанятый, чеки в «Мой налог») ·
конвейер датамайна на Python. Языки интерфейса MVP: русский и английский.

## 6. Структура репозитория (план; создаётся по мере работы)
| путь | что |
|---|---|
| `docs/` | план, решения, этапы, архитектура — источник контекста для Claude |
| `apps/web/` | Next.js: сайт, карта, карточки, поиск, аккаунты, админка |
| `pipeline/` | Python: выгрузка ERDB/Smithbox, пересчёт координат, импорт в базу |
| `db/` | схема и миграции Postgres |
| `data/` | обработанные данные (JSON/CSV — только факты, без файлов игры) |
