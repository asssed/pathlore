> Владелец — Тим (GitHub: `asssed`). Репозиторий: https://github.com/asssed/pathlore (приватный), локально — `C:\Users\timkr\Desktop\Pathlore`.

## 1. Что это
Веб-приложение с интерактивными картами и гайдами по играм: игрок находит нужное быстрее, чем через Google.
Первая игра — **Elden Ring + Shadow of the Erdtree**, публичный запуск **8 февраля 2027**; вторая — Baldur's Gate 3 (~18 апреля 2027).
Козыри: умный поиск на естественном языке (только из нашей базы, со ссылкой на точку карты), трекинг прогресса
с синхронизацией ПК↔телефон, официальные названия на всех языках из локализации игры; позже — импорт сейва и десктоп.

Полный план (утверждён 4 ноября 2026): [docs/plan.md](docs/plan.md), он же — артефакт https://claude.ai/artifact/AdjdL3pYY7XcGb9BmuG4bo.

## 2. С чего начинать каждый чат
1. Прочитать этот файл.
2. Открыть [docs/roadmap.md](docs/roadmap.md) — календарь и чек-лист текущего этапа.
3. Свериться с [docs/decisions.md](docs/decisions.md) — все принятые решения; не пересматривать их без запроса Тима.
4. По теме: [docs/architecture.md](docs/architecture.md) (техника), [docs/data-sources.md](docs/data-sources.md) (источники и лицензии),
   [docs/plan.md](docs/plan.md) (продукт целиком).

В конце работы: отметить сделанное в чек-листе этапа, новые решения — строкой в `decisions.md` (с датой и «почему»).

## 4. Жёсткие правила (нарушение = юридический или репутационный риск)
1. **Данные только легальные:** датамайн игры (ERDB, Smithbox), вики под CC BY-SA 4.0 (Eldenpedia, с атрибуцией),
   публичные данные Steam, ручная проверка. **Нельзя** копировать Mapgenie, Fextralife, Game8 и любые закрытые базы —
   ни копией, ни «с другим дизайном».
2. Тексты под CC BY-SA — только с атрибуцией; они бесплатны для всех и не могут быть платной частью. Pro — это **функции**.
3. **Файлы игры не коммитим и не публикуем** (`*.bdt`, `*.bhd`, `*.dcx`, `regulation.bin`, распакованные ресурсы) —
   только извлечённые факты (статы, координаты, названия). Локальные выгрузки — в `data/` (в `.gitignore`).
4. `eldenring.exe` и оригинальные файлы игры не изменяем. Распаковка — только в отдельную папку.
5. **Персональные данные пользователей из РФ хранятся в России** (российский хостинг). За рубеж (например, в ИИ-сервис)
   уходят только обезличенные данные — текст запроса без идентификаторов.
6. **Умный поиск отвечает только из нашей базы.** Нет совпадения → честно «не нашёл». Каждый ответ — ссылка на сущность/точку карты.
7. Секреты (`.env`, ключи, пароли) никогда не попадают в репозиторий.
8. **ИИ-API (Anthropic) не поддерживает Россию.** Аккаунт консоли и ключи — только у Тима (ОАЭ); участников проекта из РФ
   в консоль не приглашаем, ключи им не передаём, API из России не вызываем — ни напрямую, ни через наш ретранслятор, ни через VPN.
   Разработчики из РФ работают с ИИ-частью через заглушку (фиктивные ответы); реальные вызовы — только с зарубежного сервера
   или с ПК Тима. Вопрос об обслуживании конечных пользователей из РФ — открыт (см. roadmap.md).

## 5. Принятые решения (кратко; полностью — decisions.md)
| Вопрос | Решение |
| --- | --- |
| Платформа | Веб-приложение (ПК + телефон); десктоп позже на той же кодовой базе |
| Монетизация | Freemium + подписка 249 ₽/мес, 1 990 ₽/год, пожизненный 2 990 ₽ для первых 500 |
| Оплата | Robokassa на самозанятость, только клиенты из РФ; международная — после личного счёта в ОАЭ |
| Игры | Elden Ring (запуск 8 февраля 2027), затем Baldur's Gate 3; не берём Fable и GTA 6 |
| Бюджет | 20 000 ₽ до запуска, без платной рекламы |
| Стек | Next.js 16 + TypeScript, Leaflet (`CRS.Simple`), PostgreSQL + pgvector + pg_trgm, Python-пайплайны, Robokassa |
| Хостинг | Один российский VPS (Docker Compose); за рубежом — только ретранслятор запросов к ИИ без ПДн |
| Умный поиск | Сначала кандидаты из базы, ИИ только выбирает из них; модель — по замеру качества и цены |

## 6. Структура репозитория
| путь | что |
|---|---|
| `docs/` | план, решения, этапы, архитектура, источники данных |
| `apps/web/` | Next.js: сайт, карта, карточки, поиск, аккаунты, админка (каркас создан на этапе 0) |
| `pipelines/<game>/` | Python: извлечение данных из игры, пересчёт координат, загрузка в базу (`pipelines/eldenring/`) |
| `db/` | схема и миграции Postgres (появится) |
| `data/` | локальные выгрузки и промежуточный JSON — **в `.gitignore`, не коммитим** |
