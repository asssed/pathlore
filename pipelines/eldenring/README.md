# Пайплайн Elden Ring

> Статус: инструкция подготовлена 2026-11-08 для этапа 1 (старт 16 ноября 2026).
> Инструменты проверены **только по их страницам на GitHub**, ни один ещё не запускался — уточняем на первом прогоне.

## Что выяснилось при подготовке (важно)

**ERDB заброшен.** Последний коммит — 31 июля 2023, последние данные — версия игры 1.10. Shadow of the Erdtree
(версия 1.12, июнь 2024) и текущая версия игры на ПК Тима (`eldenring.exe` 2.7.2.0, файл от 2026-11-03) он не знает.
Его команды `source` / `map` / `icons` к тому же требуют игру, распакованную UXM. Поэтому в конвейере ERDB —
только справочник для базовой игры (MIT: можно смотреть, как он собирает статы предмета из нескольких параметров),
а основная работа — на поддерживаемых инструментах (решение D-023):

| Задача | Инструмент | Что известно | Лицензия |
|---|---|---|---|
| Распаковка `Data0–3.bdt` (и архивов DLC) | [Nuxe](https://github.com/JKAnderson/Nuxe/releases) — преемник UXM | Elden Ring поддерживает; DLC на странице не упомянут — проверить | GPL-3.0 |
| Запасной распаковщик | [UXM Selective Unpack](https://github.com/Nordgaren/UXM-Selective-Unpack) | «Updated for Elden Ring DLC» (v2.3) | — |
| Параметры, тексты (FMG), карты (MSB), текстуры → XML / DDS | [WitchyBND](https://github.com/ividyon/WitchyBND) | Elden Ring 1.12 (SotE) с версии 2.10; MSB для ER; работает из командной строки; Paramdex встроен | GPL-3.0 |
| Ручная сверка, просмотр данных с именами строк | [Smithbox](https://github.com/vawser/Smithbox) | Активно развивается; читает архивы без распаковки; GUI | MIT |
| Имена параметров и строк | [Paramdex](https://github.com/soulsmods/Paramdex) | Определения ER — «в основном официальные, дополнены после обновлений» | — |

Инструменты под GPL-3.0 мы только **запускаем** как внешние программы; их код в репозиторий не попадает,
лицензию нашего кода и полученных фактов это не затрагивает.

**Самое трудное — координаты.** Похожий проект [er-wiki](https://github.com/kyagara/er-wiki) (тоже на Smithbox и WitchyBND)
прямо пишет, что не знает, как достать места предметов (на карте и дроп с врагов). Наш путь: файлы карт MSB →
расстановка сокровищ и врагов с их ID → связь с таблицами лута (`ItemLotParam_map`, `ItemLotParam_enemy`) →
мировые координаты → калибровка по 5–10 точкам. Оценку плана «70–85% меток автоматически» подтвердим только после первого прогона.

## Шаги для Тима

Правила (CLAUDE.md §4): `eldenring.exe` и файлы в папке игры **не изменяем**, кнопки Patch/«пропатчить exe» **не нажимаем**,
всё распакованное — **вне** репозитория. Инструменты скачиваем только по ссылкам выше (официальные страницы на GitHub).

1. **Папка для данных.** Создать `E:\PathloreData\` с подпапками `tools\` и `eldenring\`.
   На диске E свободно 564 ГБ (на 2026-11-08) — хватит с большим запасом; игра занимает 51 ГБ.
2. **Nuxe.** Скачать последний релиз со страницы
   [github.com/JKAnderson/Nuxe/releases](https://github.com/JKAnderson/Nuxe/releases), распаковать в `E:\PathloreData\tools\Nuxe\`.
3. **Распаковка.** Запустить Nuxe:
   - игра: `E:\SteamLibrary\steamapps\common\ELDEN RING\Game`;
   - куда распаковывать: `E:\PathloreData\eldenring\unpacked\`;
   - только **распаковка**, без патча.
   Если Nuxe не даёт выбрать папку и хочет распаковать прямо в папку игры, или спрашивает про патч — **остановиться и прислать
   скриншот**. Если можно выбрать, что распаковывать, — достаточно папок `msg`, `menu`, `map`; иначе распаковать всё.
4. **WitchyBND.** Скачать последний релиз со страницы
   [github.com/ividyon/WitchyBND/releases](https://github.com/ividyon/WitchyBND/releases), распаковать в `E:\PathloreData\tools\WitchyBND\`.
   Встраивание в контекстное меню Windows при первом запуске — по желанию, нам не нужно.
5. **Написать Claude «распаковано»** — дальше конвертацию и разбор Claude делает сам из командной строки.
6. **После покупки Shadow of the Erdtree** (до 13 декабря 2026) — повторить шаг 3: появятся архивы DLC.

Smithbox ставить не нужно, пока Claude не попросит: ему нужны .NET 7 Desktop Runtime + ASP.NET Core Runtime
и видеокарта с Vulkan 1.3.

## Что делает Claude после распаковки

| Данные | Откуда | Во что |
|---|---|---|
| Параметры: оружие, броня, талисманы, расходники, пеплы войны, лут, магазины | `Game\regulation.bin` (лежит в папке игры, распаковка не нужна; копируем в `E:\PathloreData`) | WitchyBND → XML → JSON |
| Названия и описания на всех языках | `msg\<язык>\*.msgbnd.dcx` | WitchyBND → XML → JSON по локалям |
| Расстановка на картах | `map\MapStudio\*.msb.dcx` | WitchyBND → XML → координаты |
| Иконки | `menu\...` (TPF) | WitchyBND → DDS → WebP (Python) |
| Карта мира | `menu\...` (тайлы карты) | склейка → тайлы Leaflet |

Результат — JSON в `data/eldenring/` (в `.gitignore`, не коммитится), затем загрузка в базу.
Скрипты — здесь, в `pipelines/eldenring/` (Python 3.14 с ПК Тима; если инструменту нужна другая версия — отдельное окружение).
