# Пайплайн Elden Ring

Появится на этапе 1 (16 ноября 2026).

План:
1. Владелец распаковывает нужные архивы игры в отдельную папку (инструкция будет здесь).
2. Скрипты извлекают предметы, тексты на всех языках, иконки, карту мира и координаты.
3. Координаты из файлов карт пересчитываются в координаты карты мира по калибровочным точкам.
4. Результат — JSON в `data/eldenring/` (не коммитится), затем загрузка в базу.

Источники и лицензии: [../../docs/data-sources.md](../../docs/data-sources.md).
