# Pathlore: итоговый план

> Утверждён 4 ноября 2026 (@Tim). Перенесён из PDF «Pathlore итоговый план» без изменений по смыслу.
> Это источник истины по продукту. Изменения решений — только через [decisions.md](decisions.md).

## Суть продукта

Веб-приложение с интерактивными картами и гайдами, где игрок находит нужное быстрее, чем через Google.
Публичный запуск с **Elden Ring — 8 февраля 2027 года**; дальше по одной крупной игре каждые 2–3 месяца.

Главное преимущество — не объём данных, а **скорость ответа**:

- **Умный поиск по каждой игре.** Понимает неточный запрос («меч с синим огнём») и отвечает только из нашей базы,
  со ссылкой на точку на карте.
- **Трекинг прогресса.** Отмечаешь найденное, карта показывает, что осталось; синхронизация между ПК и телефоном.
- **Официальные названия на всех языках.** Берём из локализации самой игры, поэтому игрок находит предмет под тем
  именем, которое видит на экране.
- **Позже — импорт сейва.** Загрузил файл сохранения, и карта сама отметила всё найденное.

## Принятые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Платформа | Веб-приложение (ПК + телефон), позже десктоп на той же кодовой базе | Бесплатная часть индексируется Google; магазины приложений забирают 15–30% |
| Монетизация | Freemium + подписка + «пожизненный доступ» для первых 500 | Расходы постоянные (ИИ, патчи, новые игры), разовая оплата их не покроет |
| Данные | Датамайн игры + вики под CC BY-SA + ручная проверка | Своё и легальное; копировать Mapgenie нельзя |
| Запуск | Elden Ring | Самые богатые открытые данные; Fable пока не трогаем |
| Аудитория | РФ (платная) + остальной мир (бесплатно до появления нероссийского счёта) | Самозанятость покрывает только клиентов из РФ |
| Оплата | Robokassa для самозанятых | Подписки + автоматические чеки в «Мой налог» |
| Бюджет | 20 000 ₽ без платной рекламы | Трафик — SEO, сообщества, стримеры |

## Роли

Claude пишет весь код и обрабатывает данные; Тим отвечает за аккаунты, деньги, проверку в игре и решения.

**Важно:** Claude не помнит прошлые чаты. Весь контекст живёт в репозитории — код, решения, этот план.

| Claude | Тим |
|---|---|
| Архитектура, фронтенд, бэкенд, база | Регистрация аккаунтов, домен, хостинг, Robokassa, ключи |
| Скрипты датамайна и пересчёт координат | ПК с Elden Ring + DLC, выгрузка файлов игры по инструкции Claude |
| Админка, карта, поиск, перевод | Проверка меток и квестов в игре (офлайн-режим) |
| Гайды, билды, ачивки — черновики | Финальная вычитка, решения по спорным местам |
| Тексты для продвижения | Публикации, общение с сообществами и стримерами |
| Документация в репозитории | Ведёт GitHub-репозиторий, деплой с паролями |

## Игры

Запуск — Elden Ring; вторая игра — Baldur's Gate 3; дальше решаем по данным после запуска.

| Очередь | Игра | Почему | Срок |
|---|---|---|---|
| 1 | Elden Ring + Shadow of the Erdtree | Лучшие открытые данные; fashion-сеты — сильная тема для этой игры | Запуск 8 фев 2027 |
| 2 | Baldur's Gate 3 | До сих пор в топе продаж Steam, огромный объём квестов и выборов | ~ апрель 2027 |
| 3, кандидат | The Witcher 3 | Волна интереса перед The Witcher 4 (2027, даты нет) | Решаем после запуска |
| 3, кандидат | Final Fantasy 7 Revelation | Выходит в Steam 8 апреля 2027 | Решаем после запуска |

Пока не берём: GTA 6 (на ПК только к концу 2027, без ПК нет датамайна), Fable (по решению Тима).

**Требование к каждой игре:** есть на ПК, у сообщества есть инструменты разбора файлов, много лута и квестов.
Для Baldur's Gate 3 доступность датамайна нужно проверить отдельно.

## Источники данных (Elden Ring)

Около 95% предметов и текстов и 70–85% меток достаются автоматически; квесты — примерно наполовину.
Это оценка Claude, её подтвердит этап 1.

| Что | Источник | Лицензия / статус | Автоматизация |
|---|---|---|---|
| Предметы, статы, иконки, карта мира | ERDB из файлов игры | MIT | Полная |
| Параметры, тексты на всех языках | Smithbox | Инструмент сообщества, обновляется | Полная |
| Координаты лута | Файлы карт игры → пересчёт в координаты карты | Своя работа | Нужна калибровка по 5–10 точкам |
| Шаги квестов, лор | Eldenpedia (wiki.gg) | CC BY-SA 4.0, нужна атрибуция | Частичная, связываем руками |
| Ачивки | Список достижений Steam | Публичные данные | Полная |
| Проверка | Игра Тима в офлайн-режиме, сейв со 100% | — | Ручная, ~20–40 часов |

**Нельзя:** Mapgenie, Fextralife и любые закрытые базы. Тексты под CC BY-SA бесплатны для всех, поэтому платная
часть — функции, а не эти тексты.

Для импорта сейва в будущем пригодится открытый RingWatch как пример: сейвы Elden Ring на ПК не зашифрованы.

| Fashion: сеты + где найти каждую часть | Да, 20–30 сетов | Pro |

## Монетизация и цены

Стартовые цены — гипотеза: 249 ₽ в месяц, проверяем на бета-тесте.

| Тариф | Цена | Что даёт |
|---|---|---|
| Бесплатный | 0 ₽ | Карта, предметы, гайды, билды, ачивки; несколько умных запросов в день |
| Pro, месяц | 249 ₽ | Безлимитный умный поиск, трекинг и синхронизация, fashion, все игры |
| Pro, год | 1 990 ₽ | То же, выгода ~33% |
| Пожизненный, первые 500 | 2 990 ₽ | Pro навсегда, все будущие игры; деньги на старте и ядро фанатов |

Ограничения:

- Пожизненный доступ закрываем после 500 продаж, иначе он съест подписочную выручку.
- Лимит самозанятости — 2,4 млн ₽ в год. Все 500 пожизненных дают ~1,5 млн ₽, остальное — подписки.
  При приближении к лимиту переходим на ИП.

## Оплата и юридическая часть

- Платежи из РФ принимаем через Robokassa на самозанятость; международные — только после появления нероссийского счёта.
- **Самозанятость при жизни в ОАЭ.** Допустима, когда клиенты в России (Т-Банк). Оплата от иностранцев через НПД
  формально не допускается.
- **Robokassa.** Работает с самозанятыми, сама создаёт чек в «Мой налог» на каждую оплату, поддерживает подписки
  (Битрикс24). Чеки включаем сразу: штраф за невыданный — 20% от суммы, повторно — 100%.
- **Документы на сайте** (нужны для Robokassa): оферта, политика конфиденциальности, страница атрибуции CC BY-SA.
- **Персональные данные россиян.** Закон требует хранить их в России, поэтому аккаунты пользователей держим на
  российском хостинге. Нужно ли уведомлять Роскомнадзор как оператора данных — уточнить у юриста.
- **Датамайн.** Серая зона: соглашения игр его запрещают, но гайд-сайты им пользуются повсеместно.
  Файлы игры не распространяем, публикуем только факты.

## Бюджет

20 000 ₽ хватает на 4 месяца до запуска с резервом ~6 000 ₽. Цифры приблизительные, уточняются при выборе сервисов.

| Статья | ₽ за 4 месяца | Комментарий |
|---|---|---|
| Домен | 1 000–2 000 | На год |
| Российский хостинг (VPS) | 2 000–3 200 | Аккаунты и данные пользователей из РФ |
| Зарубежный хостинг / CDN | 0 | Бесплатные тарифы на старте |
| Умный поиск (ИИ) | 0–3 000 | Зависит от трафика и модели |
| Консультация юриста | 3 000–5 000 | Один раз, до первых платежей |
| Резерв | ~6 000 | Непредвиденное |
| Robokassa | 0 | Только комиссия с каждого платежа |

Не входит: платная реклама, аккаунт Apple-разработчика, лицензия в ОАЭ.
Одна консультация налогового юриста до приёма первых платежей: НПД из ОАЭ, персональные данные, оферта.

## Продвижение

Без рекламного бюджета ставим на SEO и сообщества; главный рычаг — тысячи страниц, которые генерируются из базы автоматически.

1. **С первого дня разработки.** Telegram-канал и девлог на DTF: как делаем, скриншоты карты. Собираем лист ожидания
   на пожизненный доступ.
2. **SEO.** Отдельная страница на каждый предмет, квест, босса и сет на русском и английском. Google и Яндекс приводят
   людей с запросов «где найти X».
3. **Бета-тест.** 50–100 игроков из Telegram, VK, DTF и Reddit, бесплатный Pro за отзывы.
4. **Стримеры.** Twitch и VK Play Live: бесплатный Pro в обмен на карту на экране во время стрима.
5. **Короткие видео.** YouTube Shorts, VK Клипы, TikTok: «где найти X за 30 секунд» со ссылкой.
6. **Сообщества.** Полезные ответы со ссылками в игровых группах и на Pikabu, без спама; на Reddit — по правилам
   каждого сабреддита.

## Риски

Самые опасные — оплата ИИ-сервиса и доступ к зарубежному хостингу из РФ: оба проверяем на этапе 0.

| Риск | Что делаем |
|---|---|
| Зарубежные ИИ-сервисы не принимают российские карты | Проверяем на этапе 0; запасной вариант — поиск на открытых моделях на своём сервере |
| Зарубежные хостинги и CDN нестабильны из РФ | Российская версия сайта на российском хостинге |
| Пересчёт координат сложнее, чем кажется | Калибровка по известным точкам; не выходит — часть меток Тим ставит через админку |
| Рынок по Elden Ring плотный | Выигрываем поиском, трекингом и русским языком, а не объёмом |
| ИИ-поиск выдумывает ответы | Отвечает только из нашей базы; без совпадения честно пишет «не нашёл» |
| Жалоба издателя на датамайн | Не распространяем файлы игры, только факты; быстро убираем по запросу |
| Тим один на проверке контента | Админка для быстрых правок; позже — предложения меток от игроков с модерацией |
| Выгорание при 7 часах в день | Недельные цели, а не «всё и сразу»; выходные обязательны |

## Метрики успеха

Главная метрика — доля поисков, после которых игрок нашёл ответ: цель 80% на бете. Цифры ниже — цели, а не прогноз.
Если через 3 месяца конверсия ниже 1%, пересматриваем, что именно платное, до добавления новых игр.

| Когда | Метрика | Цель |
|---|---|---|
| Бета | Поиск нашёл ответ (кнопка «нашёл?») | ≥ 80% |
| Бета | Вернулись через 7 дней | ≥ 30% |
| Бета | Ошибок в метках на 100 проверенных | ≤ 3 |
| 3 месяца после запуска | Регистрации | 5 000 |
| 3 месяца после запуска | Конверсия в платных | 3–5% |
| 3 месяца после запуска | Продано пожизненных | 300–500 |
